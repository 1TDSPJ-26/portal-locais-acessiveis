# Labels recomendadas

Crie as labels antes de liberar os formulários de Issue.

| Nome | Cor | Uso |
|---|---|---|
| `tipo:feature` | `1D76DB` | Nova funcionalidade |
| `tipo:bug` | `D73A4A` | Defeito |
| `tipo:teste` | `5319E7` | Planejamento ou resultado de teste |
| `tipo:documentacao` | `0075CA` | Documentação |
| `tipo:infraestrutura` | `0E8A16` | Build, deploy e configuração |
| `tipo:acessibilidade` | `006B75` | Auditoria e correção de acessibilidade |
| `bloqueada` | `B60205` | Demanda impedida de avançar |
| `precisa-refinamento` | `FBCA04` | Issue ainda não está pronta |
| `release` | `0052CC` | Item relacionado ao fechamento do CP |

Não duplique prioridade, esforço, CP ou squad em labels se essas informações já estiverem nos campos do Project.
